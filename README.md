# QuikNote 📝

QuikNote is a simple React-based notes application where users can
create, manage, and access their notes easily.

This project was built as a mini project to practice React,
Redux, and frontend development concepts.

## Features

- Create notes with a title and content
- View saved notes
- Edit existing notes
- Delete notes
- Copy note content
- Share notes
- Search notes
- Store notes locally using localStorage

## Tech Stack

- React.js
- Redux Toolkit
- Tailwind CSS
- Vite
- JavaScript
- localStorage

## Getting Started

### 1. Clone the repository

git clone https://github.com/itsparvgoyal/QuikNote.git

### 2. Navigate to the project

cd Folder

### 3. Install dependencies

npm install

### 4. Start the development server

npm run dev

The application will run on your local development server.
